# ai

Two small sites I designed and built for my AI automation work.

## Delegi site (`delegi.html`)

Landing page for Delegi, an AI automation studio. It explains three agents (lead and outreach, content and SEO, voice follow up), shows a live looking pipeline widget and drives to a strategy call.

## Lead magnet (`index.html`, `get-guide_4.html`)

A gated guide: **10 Business Processes You Can Automate with AI**, written for small and family businesses. Visitors leave an email and get the PDF (`10_AI_Solutions_Guide_Alina.pdf`). Each of the 10 playbooks covers the problem, the tools with real prices and the expected result.

## Stack

Plain HTML, CSS and JavaScript. No build step: open any file in a browser.
